# Color Life — app

Conway's Game of Life with colour hints and a predict mode, packaged as:

- **Android:** a signed `.apk` you can install directly, without the Play Store.
- **iPhone / iPad:** an installable web app, without the App Store.

Every push to `main` rebuilds both automatically (see `.github/workflows/build.yml`).

## Install

### Android
1. On your phone, download **[ColorLife.apk](../../releases/latest/download/ColorLife.apk)** (latest release).
2. Open the file. If Android asks, allow your browser or file manager to **Install unknown apps**.
3. Newer versions install over the old one; your phone keeps the app.

### iPhone / iPad
1. Open **https://tvaliashvilisandro.github.io/color-life-app/** in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. It opens full screen from its own icon and works offline.

## Project layout

| Path | What it is |
| --- | --- |
| `www/` | The game itself (HTML/CSS/JS), plus the web-app manifest, offline worker and icons |
| `android/` | Native Android project generated by [Capacitor](https://capacitorjs.com), which wraps `www/` |
| `capacitor.config.json` | App id, name and colours |
| `.github/workflows/build.yml` | Builds the APK, publishes it as a release, deploys `www/` to GitHub Pages |

## Building the APK yourself

Needs Node 22+, JDK 21 and the Android SDK (Android Studio installs it).

```sh
npm ci
npx cap sync android
cd android && ./gradlew assembleRelease
# → android/app/build/outputs/apk/release/app-release.apk
```

## Signing

APKs are signed with `android/app/sideload.keystore` (password `colorlife`), which is committed to the repo so
every build uses the same key and updates install cleanly. That's fine for sharing with friends, but anyone with the
repo could sign an APK as this app. Before a wider release or the Play Store, create a private keystore and add these
repository secrets; the build uses them automatically when they're set:
`ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
Switching keys means people uninstall the old version once.

## A native iOS app later

Apple only allows installing native apps outside the App Store for registered test devices. That needs a paid Apple
Developer account and a Mac (or a macOS GitHub runner): `npx cap add ios`, then sign an ad-hoc build.
