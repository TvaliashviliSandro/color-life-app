# Color Life

A puzzle game built on Conway's Game of Life: you see a small board, predict what every cell does in the
next step, then watch it happen. Each puzzle takes 10–30 seconds.

- **▶ Play:** pick a difficulty from Very easy (3–4 blocks in the middle of a 5×5 board) to Extreme
  (18–26 blocks across a 10×10 board). Every puzzle is new. Too many mistakes cost a heart (5 hearts, one refills
  every 15 minutes). After each puzzle the board zooms out and the pattern plays on, so you can see where it was
  heading. First-time players get a 5-lesson tutorial, one rule per lesson.
- **♾️ Endless:** your answer becomes the next puzzle, so you follow one long-lived pattern step after step.
  3 lives per run. Here the board's edge is a wall: nothing exists outside it.
- **📅 Daily:** the date is the seed, so everyone gets the same puzzle each day. Share an emoji result
  (🟩 right, 🟥 wrong, 🟨 missed birth) and keep a daily streak.
- **⚡ Rush:** as many perfect answers as you can in 60 seconds.
- **🧪 Playground:** the original Color Life sandbox. Draw on an endless board, press Start and watch it
  evolve, with colour hints for what survives, dies and is born next.
- **Challenge a friend:** after a Play puzzle, share a link to that exact board. The puzzle travels inside the
  link (`#puzzle=v1.<difficulty>.<size>.<cells>[.<stars>]`), so no server is needed; your friend solves it and
  sees how you did. Links can also be pasted in the app (Play → "Open a puzzle link from a friend").
- **Leaderboard:** a tab per difficulty (stars on that difficulty) plus Overall, where stars are weighted by
  difficulty (×1 up to ×12) so farming Very easy doesn't win. Other players are placeholders until online
  leaderboards (e.g. Google Play Games) are connected.
- **🎨 Themes:** System, Light and Dark are free (System follows the phone). Colour themes unlock with coins.

## Ads, purchases and the playtest

- Every puzzle has **3 hearts**; each wrong Check costs one and flags the wrong cells (missed births only as a count).
- Out of hearts → **Continue** for +1 heart: first a rewarded ad, then 50, 100, 200… coins. Or give up and see the answer.
- **Abilities** cost coins (Peek, Counter, Paintball, Rocket, Birth scan, Shield). Allowed in Play, Daily and Endless, not Rush.
- **End-of-puzzle popup**: a replay, coins earned, and "Check mistakes" with a plain-language reason for every wrong cell.

| | Android app (Play Store version) | Web / iPhone version (playtest) |
|---|---|---|
| Rewarded ads | Real AdMob ads (`www/js/monetize.js`) | Labelled fake ad |
| Coin packs | Google Play Billing, prices from Play | Labelled test purchase, nothing charged |
| Starting coins | 0 | 5,000 once |
| Leaderboard | Hidden until real online rankings exist | Placeholder players |

Ad unit and AdMob settings live in `www/js/config.js`. Play Store steps: **[store/PLAY_STORE.md](store/PLAY_STORE.md)**.

It ships as an Android `.apk` and an installable web app for iPhone, both without an app store.
Every push to `main` rebuilds both automatically (see `.github/workflows/build.yml`).

## Install

### Android
1. On your phone, download **[ColorLife.apk](../../releases/latest/download/ColorLife.apk)** (latest release).
2. Open the file. If Android asks, allow your browser or file manager to **Install unknown apps**.
3. Newer versions install over the old one; your phone keeps the app.

### iPhone / iPad
1. Open **https://tvaliashvilisandro.github.io/color-life-app/** in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. It opens full screen from its own icon and works offline.

## Resetting everyone's progress

Progress is saved on each device. To wipe it for all players, change `KEY` in `www/js/store.js` to a new
name and add the old one to `OLD_KEYS`; every player starts fresh on their next launch.

## Project layout

| Path | What it is |
| --- | --- |
| `www/js/puzzles.js` | Puzzle generator: difficulty presets, seeded random boards, boring-board filter, tutorial, Endless patterns |
| `www/js/sim.js` | The zoom-out replay shown after a puzzle |
| `www/js/life.js` | Game of Life rules |
| `www/js/store.js` | Saved progress: hearts, coins, streaks, daily results |
| `www/js/app.js` | Screens and gameplay |
| `www/js/playground.js` | Playground (free-play sandbox) |
| `www/` | Also the page, styles, web-app manifest, offline worker and icons |
| `tests/` | `npm test`: checks every difficulty generates fair, on-spec, deterministic puzzles, and Endless patterns last |

| `capacitor.config.json` | App id, name and colours |
| `.github/workflows/build.yml` | Builds the APK, publishes it as a release, deploys `www/` to GitHub Pages |

## Building the APK yourself

Needs Node 22+, JDK 21 and the Android SDK (Android Studio installs it).

```sh
npm ci
npx cap sync android
cd android && ./gradlew assembleRelease
# → android/app/build/outputs/apk/release/app-release.apk
```

## Signing

- **Sideload APK** (GitHub releases): signed with `android/app/sideload.keystore` (password `colorlife`), committed so
  every build can update the last one. Fine for friends; not secret.
- **Play Store bundle** (`.aab`): signed with your private **upload key**, which lives only in GitHub secrets
  (`UPLOAD_KEYSTORE_BASE64`, `UPLOAD_KEYSTORE_PASSWORD`, `UPLOAD_KEY_ALIAS`, `UPLOAD_KEY_PASSWORD`). The bundle is
  built only when those exist, and is attached to the workflow run as `ColorLife-play-bundle`, not to the public release.
  See [store/PLAY_STORE.md](store/PLAY_STORE.md).

The two versions are signed differently, so someone who sideloaded the APK must uninstall it once before installing
from the Play Store.

## A native iOS app later

Apple only allows installing native apps outside the App Store for registered test devices. That needs a paid Apple
Developer account and a Mac (or a macOS GitHub runner): `npx cap add ios`, then sign an ad-hoc build.
